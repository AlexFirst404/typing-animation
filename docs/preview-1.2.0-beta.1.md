# 1.2.0-beta.1 — Local sound and visual-preset preview

This is a local preview for **Minecraft 26.3 / NeoForge**. It is not a published release. Public project
descriptions and platform release metadata remain unchanged.

## Changes

- Four typing-sound families: **Typewriter, Mechanical, Soft and Laptop**. Each includes key, space, deletion
  and Enter feedback. Input sounds are optional and **off by default**, including after migration from an older config.
- Seven saved sound controls: `typingSounds=false`, `soundPreset=MECHANICAL`, `soundVolume=0.35` (0–1),
  `soundPitch=1.0` (0.6–1.6), `soundVariation=true`, `soundOnDelete=true`, `soundOnEnter=true`.
- Six visual presets: **Default, Minimal, Soft, Bouncy, Wave and Glitch**. They adjust motion and cursor settings
  while preserving audio, the mod's enabled state, field toggles, focus behaviour and the options button.
- Four settings tabs: **Animations, Cursor, Fields and Sound**. Choosing a visual preset stages it; pressing
  **Apply** changes the visual settings. Manual edits are recognised as Custom. Controls retain the live preview.
- An explicit sound audition plays a short rhythm without requiring typing audio to be enabled. It respects
  the configured volume and Minecraft's master volume, and stops scheduling when the screen closes or typing starts.

Normal audio requires the mod and typing sounds to be enabled, a positive sound volume and an enabled field.
It follows accepted input only: a paste produces at most one sound, and initial contents, navigation and
programmatic text changes stay quiet. Deletion and Enter can be muted separately. A short repeat interval and
voice cap prevent unrestricted overlap.

The audio library has **36 original procedural Ogg samples across 16 events**. They are generated by
[`scripts/generate-typing-sounds.py`](../scripts/generate-typing-sounds.py) using seeded synthesis, without
downloaded samples or recordings. The script's `--check` mode checks reproducibility without changing assets.

## По-русски

Локальная версия для **Minecraft 26.3 / NeoForge** добавляет четыре звуковых профиля и шесть готовых наборов
анимации. Звук изначально выключен, старые настройки сохраняются. Визуальный набор сначала выбирается,
затем применяется кнопкой **«Применить»**; звуковые настройки и выбранные поля при этом не меняются.

В настройках четыре вкладки и кнопка прослушивания. Вставка текста даёт не более одного звука, перемещение
курсора и автоматическое заполнение полей остаются тихими. Проверки ядра, полный игровой тест 26.3 NeoForge
и сборка конечного JAR пройдены. Готовый JAR также прошёл полный тест в отдельном клиенте с установленным
NeoForge 26.3.0.34-beta, без ошибок мода, звуковых ресурсов или отрисовки. Это локальное превью без публикации.
