# 1.5.0-beta.2 · Settings button visibility

- Added a separate **Show Button In Game** switch in **Fields**, available in Basic and Detailed mode on every loader. Turn it off to hide the Typing Animation entry in Options opened from the pause menu; the main-menu Options entry remains available.
- Forge and NeoForge now recognize their native Mods configuration entry, allowing the existing global **Options button** switch to work there. Fabric/Quilt still use Mod Menu for global hiding.
- Saved interface choices stay separate from animation presets and sound packs. Existing configurations keep the button visible by default.
- Includes the optional CommandBlockUIOverhaul and Better Command Block UI adapters from beta.1. See [their notes](changelog-1.5.0-beta.1.md) and [the popular-mod survey](compatibility-audit-2026-11-13.md).

Local preview for testing before publication.

## По-русски

- Во вкладку **«Поля»** добавлен отдельный переключатель **«Кнопка в игре»**, доступный в базовом и подробном интерфейсе на всех загрузчиках. Выключите его, чтобы скрыть кнопку Typing Animation в настройках, открытых из меню паузы. Вход через настройки главного меню сохраняется.
- Forge и NeoForge учитывают вход через свой список модов: прежний общий переключатель кнопки теперь работает и там. На Fabric/Quilt для общего скрытия используется Mod Menu.
- Настройки интерфейса не меняются при применении пресетов анимации и звуковых наборов. Старые конфигурации сохраняют видимую кнопку по умолчанию.
- Сохранены адаптеры CommandBlockUIOverhaul и Better Command Block UI из beta.1. [Предыдущие изменения](changelog-1.5.0-beta.1.md), [анализ популярных модов](compatibility-audit-2026-11-13.md).

Локальная тестовая сборка перед публикацией.
