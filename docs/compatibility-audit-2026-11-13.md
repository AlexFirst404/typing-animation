# Text-input compatibility audit — 13 November 2026

Audit date: **13 November 2026, Europe/Moscow**. Baseline: Typing Animation **1.4.0**. This is a source-level survey of eleven popular projects, not a runtime compatibility certification.

The strongest next candidates are **YACL string controllers, FTB Library text boxes and REI search**. These inspected widgets draw their own editable text outside the vanilla widget methods intercepted by Typing Animation. **Modern UI's text engine** is a separate priority because it replaces the rendering path of vanilla text boxes themselves. The other seven projects retain vanilla rendering in the inspected fields and should enter the regression test matrix before receiving dedicated adapters.

## Evidence and limits

- Download totals were read from the projects' official Modrinth API responses, except FTB Library, whose **CurseForge NeoForge/Forge project** is counted. These are platform-specific lifetime totals, not unique players, current active users or comparable totals across all platforms. No claim of a global popularity ranking is made.
- The release column names one **published test candidate** within Typing Animation's supported Minecraft range. It is not a claim that every project supports every Minecraft version or loader listed by Typing Animation.
- Source links below are pinned to the exact inspected GitHub revisions. A branch snapshot is **not proven byte-equivalent to the listed published JAR**. The report does not infer an artifact-level result from that association.
- **None of these eleven mods was launched with Typing Animation during this survey.** No crash or rendered-pixel regression is reported as reproduced. “High risk” means a concrete bypass or overlapping rendering implementation is visible in source; “expected covered” means the inspected widget retains the vanilla path, pending client tests.
- CommandBlockUIOverhaul, Better Command Block UI and Scholar are handled separately. Their adapter implementation/testing is not replaced by this survey.

## What the existing hooks cover

The older client integrations intercept `EditBox.renderWidget` and `MultiLineEditBox.renderContents`. On Minecraft 26.3 the corresponding hooks are `extractWidgetRenderState` and `extractContents`. A subclass that calls its vanilla superclass normally reaches these hooks. A field that only reuses a text-data model, or draws through a different widget hierarchy, does not thereby receive animation.

The global switch and **Fields → Other Fields** or **Multi-line Fields** must also be enabled. A disabled field category is not an incompatibility. Client-side typing sound follows accepted input through separate widget hooks; rendering inheritance alone does not establish sound/input compatibility.

Local references: [field-category gates](../core/src/main/java/dev/typinganimation/core/FieldKind.java), [1.21.1 EditBox hooks](../mc/1.21.1/src/main/java/dev/typinganimation/mixin/EditBoxMixin.java), [26.3 EditBox hooks](../mc/26.3/src/main/java/dev/typinganimation/mixin/EditBoxMixin.java), [26.3 multiline hooks](../mc/26.3/src/main/java/dev/typinganimation/mixin/MultiLineEditBoxMixin.java).

## Priorities after the command-block adapters

1. **YACL string controllers.** Their installation reach is large and their custom text/caret code gives a specific integration point. Keep search-field coverage separate and preserve validation, live versus deferred application, dropdown behavior and right-aligned/scissored values.
2. **FTB Library TextBox and MultilineTextBox.** Support the library widgets once, then test real Quests configuration/search, Chunks waypoint naming and the NBT editor individually. Inspect older package/API variants before claiming coverage across versions.
3. **REI overlay search.** A narrow adapter can preserve the existing formatter, prefix syntax, selection, horizontal scroll and search-result updates.
4. **Modern UI text engine.** Treat this as a renderer integration task rather than a generic custom field. Font shaping, fractional advances, bidirectional text, selection and IME composition must remain correct. A global redirect of every Font draw call would also touch static labels and is not an appropriate shortcut.
5. **Regression fixtures for JEI, EMI, AE2, Refined Storage, Create, Cloth Config and Chat Patches.** Confirm which already work before adding more mixins.

## Acceptance plan

For each proposed integration, use an isolated client with a concrete published artifact and required dependencies, then preserve the artifact hashes, loader version and Minecraft anchor. Keep three distinct verdicts: **confirmed runtime pass**, **reproduced missing animation**, and **source-only risk**.

Exercise appearance and removal effects, both cursor axes, selection, long horizontal/vertical scrolling, styled commands/search prefixes, supplementary Unicode, paste, completion and undo where provided. Compare settled native pixels with animation disabled. Confirm enabled/disabled field categories and that refused input, initialization and navigation stay silent. Sounds should fire once for accepted input. Finally check absence of the optional mod and at least one pair of simultaneous UI mods to detect mixin interaction.

Local research receipts are in `.research/popular-mod-compat/`: project and version API responses, `selected-releases.json` and pinned source-snapshot references. They are inspection material, not evidence of executed clients. Third-party source is not included in the release artifacts.

## Коротко на русском

По просмотренным исходникам отдельной совместимости, вероятнее всего, потребуют **строковые настройки YACL**, **TextBox/MultilineTextBox из FTB Library** и **поиск REI**: они рисуют ввод самостоятельно. У YACL поиск и строковые настройки устроены по-разному, поэтому вывод относится к конкретным контролам. **Modern UI** — отдельный случай: включённый текстовый движок заменяет отрисовку даже обычных полей, и его нужно проверять в обоих режимах.

В просмотренных полях **JEI, EMI, AE2, Refined Storage, Create, Cloth Config и Chat Patches** сохраняется стандартная отрисовка. Это снижает риск, но не подтверждает работу всех экранов этих модов. Эти одиннадцать проектов здесь исследованы по исходникам; игровые прогоны с ними не выполнялись. Счётчики загрузок выше относятся к указанной площадке, а не к числу уникальных игроков.

Следующий практичный шаг — игровые проверки YACL и FTB Library, затем поиска REI. Для Modern UI потребуется отдельная работа со шрифтовым движком, включая выделение, курсор и ввод сложных письменностей. Проверки CommandBlockUIOverhaul, Better Command Block UI и Scholar относятся к отдельной матрице новой сборки.
