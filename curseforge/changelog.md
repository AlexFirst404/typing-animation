# 1.5.0 · More moods, more editors

- **16 built-in visual presets:** ten new combinations join Default, Minimal, Soft, Bouncy, Wave and Glitch. Try Terminal, Typewriter, Snappy, Floating, Elastic, Retro, Swing, Orbit, Paper and Cinematic. Choose a preset, press Apply, then adjust it in the live preview. Applying a visual preset keeps your sound, field and menu preferences.
- **Hide the in-game settings button:** Fields → Show Button In Game works in Basic and Detailed mode, on every loader, without Mod Menu. Hide the entry in Options opened from the pause menu while retaining access through the main menu. The separate global button switch now also recognizes Forge/NeoForge's native Mods configuration entry.
- **CommandBlockUIOverhaul:** optional animation, deletion, smooth caret and accepted-input sound support for Forge 1.20.1 and NeoForge 1.21.1.
- **Better Command Block UI:** optional support for its Fabric/Quilt editor across the supported API groups, preserving command colours, indentation, wrapping, selection, scrolling and editing. Both command editors use Fields → Multi-line Fields. Legacy `§`-formatted chunks in Better retain their native rendering.
- Loading commands, switching editors, rejected input and programmatic changes remain quiet. The upstream editor mods remain optional and keep their own dependencies. Better Command Block UI on 26.3 requires its matching Fabric API; Typing Animation itself does not.

## По-русски

- **16 готовых визуальных пресетов:** к прежним шести добавлены десять сочетаний анимации, курсора и темпа. Выберите набор и нажмите **«Применить»**, затем подстройте его в предпросмотре. Звук, выбранные поля и настройки кнопок меню сохраняются.
- **Скрытие кнопки в игре:** **«Поля → Кнопка в игре»** работает в базовом и подробном интерфейсе, на всех загрузчиках и без Mod Menu. Кнопка скрывается в настройках из меню паузы; вход через главное меню сохраняется. Общий переключатель также учитывает встроенный список модов Forge/NeoForge.
- **CommandBlockUIOverhaul:** анимации ввода и удаления, плавный курсор и звуки на Forge 1.20.1 и NeoForge 1.21.1.
- **Better Command Block UI:** необязательная совместимость с редактором Fabric/Quilt. Подсветка команд, отступы, переносы, выделение и прокрутка сохраняются. Оба редактора управляются пунктом **«Поля → Многострочные поля»**. Фрагменты с `§` в Better сохраняют родную отрисовку.
- Загрузка команд, переключение редакторов, отклонённый ввод и программные изменения не запускают звук печати. У сторонних редакторов остаются их собственные зависимости; Better Command Block UI для 26.3 требует подходящий Fabric API, а сам Typing Animation — нет.
