## 1.0.0: first release

- Smooth typing animations for chat, the command line and most other text fields, including multi-line boxes where the game version allows it.
- 11 appear styles and 5 remove styles (either animation can also be turned off), and 10 easing curves plus Auto.
- Smooth reflow, scrolling and cursor movement.
- Pasted text, chat history and command completions are typed out one character at a time.
- Settings screen with a live preview and a Demo button, opened from the Options screen, the NeoForge/Forge mods list or Mod Menu on Fabric. The settings are stored in `config/typinganimation.json`.
- Client-side only, and Fabric API is not required. When no animation is running, the text looks exactly as it does in vanilla.
- Builds for Minecraft 1.20–1.20.1, 1.21–1.21.1, 1.21.4, 1.21.5, 1.21.6–1.21.8, 1.21.9–1.21.10, 1.21.11, 26.1–26.1.2, 26.2 and 26.3 on NeoForge, Forge and Fabric. On NeoForge 1.20.1, use the Forge build.

## 1.0.0: первый выпуск

- Плавная анимация ввода в чате, командной строке и большинстве других полей, в том числе в многострочных, где это позволяет версия игры.
- 11 стилей появления и 5 стилей удаления (каждую из этих анимаций можно выключить), 10 кривых анимации и режим «Авто».
- Плавный сдвиг текста, прокрутка и движение курсора.
- Вставленный текст, сообщения из истории чата и автодополнение команд печатаются по одному символу.
- Экран настроек с живым предпросмотром и кнопкой «Демо». Его можно открыть из «Настроек», из списка модов NeoForge/Forge или через Mod Menu на Fabric. Настройки хранятся в `config/typinganimation.json`.
- Мод работает только на клиенте, Fabric API не нужен. Когда анимация не идёт, текст выглядит точно так же, как в ванилле.
- Сборки для Minecraft 1.20–1.20.1, 1.21–1.21.1, 1.21.4, 1.21.5, 1.21.6–1.21.8, 1.21.9–1.21.10, 1.21.11, 26.1–26.1.2, 26.2 и 26.3 на NeoForge, Forge и Fabric. Для NeoForge 1.20.1 используйте Forge-сборку.
